# CloudImage Converter
Навчальний хмарний сервіс. Потрібен Node.js 20 або новіший.

## Локальний запуск
1. Відкрити папку у VS Code.
2. У терміналі виконати `npm install`, потім `npm start`.
3. Відкрити http://localhost:3000.

## Azure VM
Створіть Ubuntu VM з публічною IP-адресою, встановіть Node.js 22 LTS, перенесіть папку через SCP або Git. Виконайте npm install та npm start. Для тимчасового тесту дозвольте TCP 3000 у NSG лише зі своєї IP-адреси. Відкрийте http://PUBLIC_IP:3000. Для публічного використання налаштуйте Nginx, HTTPS, обмеження запитів та systemd для автоматичного запуску Node.js; закрийте зовнішній порт 3000. Для Nginx встановіть client_max_body_size 51m. Azure може тарифікувати VM, диски та IP.

Файли зберігаються на диску VM 24 години. Це одновузловий хмарний застосунок, а не розподілена Grid-система. Для публічного виробничого сервісу потрібні додаткові квоти сховища, моніторинг і захист від зловживань.
